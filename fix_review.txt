## 问题列表

### [高] 逻辑 / 设备不匹配: `_denoiser_step` 输入张量未迁移到模型设备
**文件**: `src/elf/pipeline.py:279-286`
**问题**: `_denoiser_step` 中通过 `torch.from_numpy(...)` 和 `torch.tensor(...)` 创建的所有张量（`z_t`、`t_t`、`scale_t`、`x_prev`）均位于 CPU，而 `self._denoiser` (ELFDenoiser) 已在 `__init__` 中通过 `self.to(self.device)` 迁移到 GPU（当 device="cuda" 时）。`forward()` 内部直接对输入 `x.float()` 后送入 `self.text_proj`（GPU 上的 nn.Linear），将触发 `RuntimeError: Expected all tensors to be on the same device`。**这是运行时必现崩溃**。
**建议**: 在 `_denoiser_step` 中所有 tensor 创建后统一加 `.to(self._denoiser.device)`，或改为先创建再迁移:
```python
z_t = torch.from_numpy(np.asarray(z, dtype=np.float32)).view(1, 1, -1).to(self._denoiser.device)
t_t = torch.tensor([t], device=self._denoiser.device)
# ... 同理处理 x_prev, z_u
```

### [高] 一致性: `enhance_batch` 未接入 denoiser 路径
**文件**: `src/elf/pipeline.py:307-371`
**问题**: `enhance()` 中新增了真实 denoiser 分支（`_enhance_with_denoiser`），但 `enhance_batch()` 完全未更新，仍然只走回退路径（`add_noise` + `denoise_with_cfg` + 占位速度场）。这导致批量增强得不到真实 flow matching 的效果，且两个公共方法的语义不一致。`enhance_batch` 也没有 `blend_alpha` 参数。
**建议**: 为 `enhance_batch` 增加 denoiser 批量路径（在 T5 hidden 空间批量处理，再批量投影回 768），与 `enhance` 保持对称。

### [高] 测试覆盖: `native_model.py` 零测试覆盖
**文件**: `src/elf/native_model.py` (全新文件, 391 行)
**问题**: 整个 `ELFDenoiser` 模型（含 `Attention`、`RMSNorm`、`SwiGLUFFN`、`ELFBlock`、`TimestepEmbedder`、`BottleneckTextProj`、`FinalLayer`、`TextRotaryEmbeddingFast` 等 ~10 个类）没有任何测试文件 (`tests/test_elf_native_model.py` 不存在)。`pipeline.py` 中新增的 `_enhance_with_denoiser` 和 `_denoiser_step` 也没有测试覆盖。
**建议**: 至少添加:
1. `ELFDenoiser` 的权重加载与 shape 校验测试（mock checkpoint）
2. `_denoiser_step` 单元测试（mock denoiser）
3. `_enhance_with_denoiser` 端到端测试（mock denoiser + mock encoder）

### [中] 模块边界: pipeline 导入 native_model 私有常量
**文件**: `src/elf/pipeline.py:25-29`
**问题**: `pipeline.py` 导入了 `native_model.py` 中以 `_` 为前缀的模块级私有常量 `_DENOISER_NOISE_SCALE`、`_LATENT_STD`、`_T_EPS`。按命名规范，`_` 前缀表示模块内部使用，不应被外部模块直接导入。
**建议**: 将这些常量改为公开名（去掉 `_` 前缀），并在 `native_model.py` 或 `__init__.py` 中正式导出；或者在 `pipeline.py` 中本地定义等价常量并注明来源。

### [中] 性能: `_encode_torch` 重构后退化为逐条处理
**文件**: `src/elf/native_encoder.py:217-222`
**问题**: 旧版 `_encode_torch` 对整个 batch 做投影 + 归一化（`projected = self._projection(pooled)` 输入 `(B, 512)`，返回 `(B, 768)`）。新版改为 `for pooled in ... reshape(-1, 512)` 逐条调用 `embed_from_pooled`，每次只处理单条 `(1, 512)` → `(1, 768)`。虽然结果等效，但对大批量编码（如 `encode_batch` 的 32 条）会产生 32 次独立的小矩阵乘法，损失了批量 GEMM 的效率。
**建议**: 保留批量投影路径，或在 `embed_from_pooled` 中添加批量支持（接受 `(B, 512)` 输入），然后在 `_encode_torch` 中直接传入整个 batch 的 pooled hidden。

### [中] 类型注解缺失: `@torch.no_grad()` 遗漏
**文件**: `src/elf/native_encoder.py:158` (`_pooled_torch`), `185` (`encode_pooled`), `198` (`embed_from_pooled`)
**问题**: 这三个方法是纯推理方法，但没有添加 `@torch.no_grad()` 装饰器。`encode` 和 `encode_batch` 有此装饰器并内部调用它们，但如果 `encode_pooled` 或 `embed_from_pooled` 被直接调用（如 pipeline 中 `self.encoder.encode_pooled(text)`），会默认启用梯度跟踪。
**建议**: 为 `_pooled_torch`、`encode_pooled`、`embed_from_pooled` 均添加 `@torch.no_grad()`。

### [中] 错误处理: `_load_checkpoint` 对 `strict=False` 过于严格
**文件**: `src/elf/native_model.py:330-334`
**问题**: 使用 `strict=False` 加载权重后，任何 missing 或 unexpected key 都会直接 `raise RuntimeError`。但 `strict=False` 的语义正是容忍不匹配的 key——如果 checkpoint 包含额外键（如 decoder 分支的 unembed 权重），不应视为致命错误。当前实现相当于 `strict=True` + 手动报错。
**建议**: 改为 `logger.warning` 记录不匹配的 key，而非直接抛异常；或至少将 unexpected keys 降级为 warning（missing keys 仍可报错）。

### [中] 控制流: `_enhance_with_denoiser` 使用 `assert` 做类型守卫
**文件**: `src/elf/pipeline.py:230-231`
**问题**: `assert self._denoiser is not None` 和 `assert isinstance(self.encoder, ELFNativeEncoder)` 用于类型收窄。这依赖 `assert` 不被禁用——Python 在 `-O` 优化模式下会跳过所有 `assert` 语句，导致后续代码在 `mypy` 层面通过但在运行时可能因 `None` 引用崩溃。
**建议**: 改为显式的 `if self._denoiser is None: raise RuntimeError(...)` 检查，或信任调用方 guard（`enhance()` 中已做了三重检查），删除此处的 assert。

### [中] 公共 API: `build_context` 缺少 docstring
**文件**: `src/elf/native_model.py:337-350`
**问题**: `build_context` 是 `ELFDenoiser` 的公共方法但完全没有 docstring，违反了项目"公共函数/类应使用清晰 docstring"的规范。
**建议**: 补全 Google 风格 docstring，说明参数和返回值语义。

### [中] 公共 API: `__init__.py` 未导出 `ELFDenoiser`
**文件**: `src/elf/__init__.py`
**问题**: `ELFDenoiser` 作为新的公共类（用于检索增强链路），未出现在 `__init__.py` 的 `__all__` 中，也未 import。用户需通过 `from src.elf.native_model import ELFDenoiser` 访问，与其他公共 API 的导入方式不一致。
**建议**: 在 `__init__.py` 中添加导出；或在 `native_model.py` docstring 中注明这是内部细节。

### [低] 命名: `_pooled_torch` 含义不够清晰
**文件**: `src/elf/native_encoder.py:158`
**问题**: 方法名 `_pooled_torch` 中 `_torch` 后缀不如 `_encode_torch` 直观——后者表示"用 PyTorch 完成编码"，前者表示"用 PyTorch 做池化"但操作的是 T5 hidden 而非池化本身。`_t5_pool` 或 `_pool_t5_hidden` 更贴切。**这是私有方法，影响有限**。
**建议**: 可选，重命名为 `_t5_mean_pool`。

### [低] 死代码: `_VOCAB_SIZE` 及其相关参数仅用于权重完整性
**文件**: `src/elf/native_model.py:51, 283-285`
**问题**: `unembed_kernel`、`unembed_bias` 和 `_VOCAB_SIZE` 仅用于加载 checkpoint 中的 decoder 分支权重，检索增强链路从不使用这些参数。代码注释已说明"仅完整承载"。虽不算严格死代码（权重重载时必须匹配 shape），但占用内存。
**建议**: 若确认检索链路永远不会使用 decoder 分支，可考虑在 `_load_checkpoint` 中跳过这些 key 的加载（`strict=False` + ignore list），然后删除这些参数声明。

### [低] 代码风格: `_enhance_with_denoiser` 中硬编码 512
**文件**: `src/elf/pipeline.py:237`
**问题**: `rng.standard_normal(512, dtype=np.float32)` 直接硬编码 512，而 `native_encoder.py` 已有 `T5_HIDDEN_DIM = 512` 常量。应该引用该常量或 `self._denoiser.text_encoder_dim`。
**建议**: 使用 `self.encoder` 的 `T5_HIDDEN_DIM` 或 denoiser 的 `text_encoder_dim`。

## 总结
- **高风险问题**: 3 (设备不匹配崩溃、enhance_batch 未接入 denoiser、零测试覆盖)
- **中风险问题**: 7 (私有常量跨模块导入、批量编码性能退化、@torch.no_grad 缺失、checkpoint 加载过严、assert 做守卫、公共方法缺 docstring、__init__ 未导出)
- **低风险问题**: 4 (方法命名、死代码参数、硬编码维度、代码风格)

**核心结论**: 此 PR 实现了 issue #37 的真实 DiT denoiser 集成，方向正确。但存在一个**严重运行时 bug**（GPU 设备不匹配导致 `_denoiser_step` 必崩）、`enhance_batch` **未同步更新**的设计缺口，以及**完全缺失测试**，建议 merge 前修复这三项高风险问题。

+def _rotate_half(x: torch.Tensor) -> torch.Tensor:
+    x = x.reshape(*x.shape[:-1], -1, 2)
+    x1, x2 = x[..., 0], x[..., 1]
+    return torch.stack((-x2, x1), dim=-1).flatten(-2)

+class TextRotaryEmbeddingFast(nn.Module):
+    """RoPE, 前 num_empty_token 个位置不旋转(前缀 token)。"""
+
+    def __init__(
+        self,
+        dim: int,
+        pt_seq_len: int = 1024,
+        theta: float = 10000.0,
+        num_empty_token: int = 0,
+    ) -> None:
+        super().__init__()
+        self.dim = dim
+        self.pt_seq_len = pt_seq_len
+        self.theta = theta
+        self.num_empty_token = num_empty_token
+
+    def forward(self, t: torch.Tensor) -> torch.Tensor:
+        seq_len = t.shape[-2]
+        main_len = max(seq_len - self.num_empty_token, 0)
+        device = t.device
+        calc_dtype = torch.float32
+
+        freqs = 1.0 / (
+            self.theta
+            ** (
+                torch.arange(0, self.dim, 2, device=device, dtype=calc_dtype)[: self.dim // 2]
+                / self.dim
+            )
+        )
+        pos = torch.arange(self.ft_seq_len, device=device, dtype=calc_dtype)
+        pos = pos / self.ft_seq_len * self.pt_seq_len
+        freqs_main = torch.einsum("n,f->nf", pos, freqs)
+        freqs_main = freqs_main.repeat_interleave(2, dim=-1)[:main_len]
+
+        parts_cos: list[torch.Tensor] = []
+        parts_sin: list[torch.Tensor] = []
+        if self.num_empty_token > 0:
+            empty = min(self.num_empty_token, seq_len)
+            parts_cos.append(torch.ones(empty, self.dim, device=device, dtype=calc_dtype))
+            parts_sin.append(torch.zeros(empty, self.dim, device=device, dtype=calc_dtype))
+        if main_len > 0:
+            parts_cos.append(torch.cos(freqs_main))
+            parts_sin.append(torch.sin(freqs_main))
+
+        cos = torch.cat(parts_cos, dim=0).to(dtype=t.dtype)
+        sin = torch.cat(parts_sin, dim=0).to(dtype=t.dtype)
+        return t * cos + _rotate_half(t) * sin
+
+    @property
+    def ft_seq_len(self) -> int:
+        return self.pt_seq_len

+class RMSNorm(nn.Module):
+    def __init__(self, hidden_size: int, eps: float = 1e-6) -> None:
+        super().__init__()
+        self.weight = nn.Parameter(torch.ones(hidden_size))
+        self.eps = eps
+
+    def forward(self, hidden_states: torch.Tensor) -> torch.Tensor:
+        input_dtype = hidden_states.dtype
+        variance = hidden_states.float().pow(2).mean(dim=-1, keepdim=True)
+        inv_std = torch.rsqrt(variance + self.eps).to(dtype=input_dtype)
+        return self.weight.to(dtype=input_dtype) * (hidden_states * inv_std)

+class Attention(nn.Module):
+    def __init__(self, dim: int, num_heads: int = 12, qkv_bias: bool = True) -> None:
+        super().__init__()
+        self.dim = dim
+        self.num_heads = num_heads
+        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
+        head_dim = dim // num_heads
+        self.q_norm = RMSNorm(head_dim)
+        self.k_norm = RMSNorm(head_dim)
+        self.proj = nn.Linear(dim, dim)
+
+    def forward(
+        self,
+        x: torch.Tensor,
+        rope_fn: TextRotaryEmbeddingFast | None,
+        attention_mask: torch.Tensor | None = None,
+    ) -> torch.Tensor:
+        bsz, seq_len, channels = x.shape
+        head_dim = self.dim // self.num_heads
+        qkv = self.qkv(x)
+        qkv = qkv.reshape(bsz, seq_len, 3, self.num_heads, head_dim)
+        qkv = qkv.permute(2, 0, 3, 1, 4)
+        q, k, v = qkv[0], qkv[1], qkv[2]
+        q = self.q_norm(q)
+        k = self.k_norm(k)
+        if rope_fn is not None:
+            q = rope_fn(q)
+            k = rope_fn(k)
+        x = F.scaled_dot_product_attention(q, k, v, attn_mask=attention_mask)
+        x = x.transpose(1, 2).reshape(bsz, seq_len, channels)
+        return self.proj(x)

+class SwiGLUFFN(nn.Module):
+    def __init__(self, dim: int, hidden_dim: int) -> None:
+        super().__init__()

+    def forward(self, x: torch.Tensor) -> torch.Tensor:

+class ELFBlock(nn.Module):
+    def __init__(self, hidden_size: int, num_heads: int, mlp_ratio: float = 4.0) -> None:
+        super().__init__()

+class TimestepEmbedder(nn.Module):
+    """时间步嵌入: sin 嵌入(256) → Linear → SiLU → Linear。"""
+
+    def __init__(self, hidden_size: int, frequency_embedding_size: int = 256) -> None:
+        super().__init__()
+        self.frequency_embedding_size = frequency_embedding_size
+        self.mlp = nn.Sequential(
+            nn.Linear(frequency_embedding_size, hidden_size),
+            nn.SiLU(),
+            nn.Linear(hidden_size, hidden_size),
+        )
+
+    @staticmethod
+    def timestep_embedding(t: torch.Tensor, dim: int, max_period: int = 10000) -> torch.Tensor:
+        half = dim // 2
+        freqs = torch.exp(
+            -math.log(max_period)
+            * torch.arange(0, half, device=t.device, dtype=torch.float32)
+            / half
+        )
+        args = t[:, None].float() * freqs[None]
+        return torch.cat([torch.cos(args), torch.sin(args)], dim=-1)

+    def forward(self, t: torch.Tensor) -> torch.Tensor:
