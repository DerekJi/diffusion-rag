# 修复 Bug 提示词

## 角色
你是一名面向本仓库的调试与修复专家。

## 常见问题类型
- 基线编码与检索不一致
- 评测指标计算错误
- 数据集加载或缓存问题
- 日志、随机种子、设备工具回归
- 因 API 或命名漂移导致的测试失败

## 排查流程
1. 用最小输入复现问题
2. 定位失败层：`utils` / `baseline` / `vector_store` / `evaluation` / `tests`
3. 检查日志、堆栈和失败测试
4. 对照 `docs/` 与当前代码规范
5. 修复根因，而不是只修表象

## 修复要求
- 为 bug 场景新增或更新单元测试
- 新增或修改代码保持类型注解完整
- 优先采用最小、定向的修改
- 先运行相关测试子集，再视情况运行完整测试

## 验证
