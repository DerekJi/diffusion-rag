## 问题列表

### [高] 死代码 / `_TIMEOUT_SECONDS` 定义但从未使用
**文件**: `src/utils/download.py:43`
**问题**: 常量 `_TIMEOUT_SECONDS = 60` 在模块顶部定义，但全文件没有任何地方引用它。`_wait_with_timeout()` 仅调用 `time.sleep(_RETRY_DELAY)`，与超时无关。
**建议**: 删除该常量；或在 `_wait_with_timeout` / 下载函数中真正实现超时逻辑（如用 `signal.alarm` 或在线程中带超时等待）。目前注释中的 "超时 60s" 并未落地。

### [高] 逻辑缺陷 / `_download_hf_dataset_with_retry` 首次下载不指定 config，可能漏下载 corpus
**文件**: `src/utils/download.py:314-316`
**问题**: 这里调用 `load_dataset(hf_name, ...)` 不传 `name` 参数（config name）。BEIR 数据集如 `BeIR/nfcorpus` 有 `corpus`、`queries` 等多个 config，`load_dataset` 在未指定时只加载默认 config（通常是 `corpus`，但也可能是不完整的子集）。对比 `src/evaluation/dataset.py:84` 的规范做法是显式传入 config name `_hf_load_with_retry("queries", hf_name, ...)`。
**建议**: 参照 `dataset.py` 的模式，分别显式下载 `corpus` 和 `queries` config：
```python
load_dataset(hf_name, "corpus", cache_dir=str(data_dir), download_mode="reuse_dataset_if_exists")
load_dataset(hf_name, "queries", cache_dir=str(data_dir), download_mode="reuse_dataset_if_exists")
```

### [高] 逻辑缺陷 / `pbar.update(0)` 在 tqdm context manager 外部，纯属无效代码
**文件**: `src/utils/download.py:327-328`
**问题**: `pbar.update(0)` 在 `with tqdm(...) as pbar:` 块结束后调用，此时进度条已关闭，该调用是无效的 no-op。且 `pbar.update(0)` 语义本身就是不更新任何进度。
**建议**: 删除该行。如需进度条覆盖验证阶段，应将验证 `load_dataset` 也放入 `with tqdm` 块内。

### [中] 命名误导 / `_wait_with_timeout` 函数名与实际行为不符
**文件**: `src/utils/download.py:175-177`
**问题**: 函数名为 `_wait_with_timeout`，docstring 写 "等待重试间隔，同时计入总超时"，但实现仅一行 `time.sleep(_RETRY_DELAY)`，没有任何超时计数或超时判定逻辑。
**建议**: 改名为 `_retry_sleep()` 或 `_wait_before_retry()`；同时修正 docstring。如果确需总超时控制，应实现对应逻辑。

### [中] 一致性 / `download_elf_weights` 缓存命中时返回路径不统一
**文件**: `src/utils/download.py:107`
**问题**: 缓存命中时，若 `models_dir / ELF_MODEL_REPO` 是目录则返回它，否则返回 `models_dir`。两种路径结构不一致（一个有子目录层级，一个没有），调用方如果拼接子路径可能出错。
**建议**: 统一返回 `models_dir`（即只需告知"模型文件在哪个目录下"），或始终返回实际存在的目录路径并在 docstring 中明确说明返回值的结构。

### [中] 一致性与维护性 / `SUPPORTED_DATASETS` 与 `src/evaluation/dataset.py` 的 `_DATASET_MAP` 重复
**文件**: `src/utils/download.py:35-39` vs `src/evaluation/dataset.py:17-22`
**问题**: 两份代码各自维护一份完全相同的 BEIR 数据集映射字典。新增数据集时需要同步修改两处，容易遗漏。
**建议**: 将 `_DATASET_MAP` 提升为 `src/config.py` 中的公共常量（如 `BEIR_DATASET_MAP`），两处 `import` 同一来源。

### [中] 测试覆盖 / 缺少 ELF 权重下载全部重试耗尽 + fallback 也失败的测试
**文件**: `tests/test_download.py`

+            logger.info("数据集 %s 验证通过 (%d 条 queries)", name, len(ds))
+            return
+        except Exception as e:
+            last_error = e
+            logger.warning(
+                "数据集 %s 下载失败 (尝试 %d/%d): %s",
+                name,
+                attempt,
+                _MAX_RETRIES,
+                e,
+            )
+            if attempt < _MAX_RETRIES:
+                _wait_with_timeout()
+
+    raise RuntimeError(
+        f"数据集 {name} ({hf_name}) 下载失败，已重试 {_MAX_RETRIES} 次: {last_error}"
+    )

+def _parse_args(argv: list[str] | None = None) -> argparse.Namespace:
+    """解析命令行参数。
+
+    Args:
+        argv: 命令行参数列表，None 使用 sys.argv。
+
+    Returns:
+        解析后的命名空间。
+    """
+    parser = argparse.ArgumentParser(
+        description="Diffusion RAG — 资产下载脚本",
+        formatter_class=argparse.RawDescriptionHelpFormatter,
+        epilog=(
+            "示例:\n"
+            "  %(prog)s --all                          下载全部资产\n"
+            "  %(prog)s --elf-weights                  仅下载 ELF-B 模型权重\n"
+            "  %(prog)s --dataset nfcorpus             仅下载 NFCorpus 数据集\n"
+            "  %(prog)s --dataset nfcorpus --cache-dir /mnt/cache  指定缓存目录\n"
+        ),
+    )
+
+    # 互斥操作
+    action = parser.add_mutually_exclusive_group()
+    action.add_argument(
+        "--all",
+        action="store_true",
+        help="下载全部资产（ELF-B 权重 + 所有 BEIR 数据集）",
+    )
+    action.add_argument(
+        "--elf-weights",
+        action="store_true",
+        help="仅下载 ELF-B 模型权重",
+    )
+    action.add_argument(
+        "--dataset",
+        type=str,
+        choices=list(SUPPORTED_DATASETS.keys()),
+        help="仅下载指定数据集",
+    )
+
+    parser.add_argument(
+        "--cache-dir",
+        type=str,
+        default=None,
+        help="缓存根目录（默认: models/ + data/）",
+    )
+
+    args = parser.parse_args(argv)
+
+    # 未指定任何操作时，默认下载全部
+    if not args.all and not args.elf_weights and not args.dataset:
+        args.all = True
+
+    return args
+
+
+def main(argv: list[str] | None = None) -> None:
+    """下载脚本入口。
+
+    Args:
+        argv: 命令行参数列表，None 使用 sys.argv。
+    """
+    args = _parse_args(argv)
+
+    if args.all:
+        download_all(cache_dir=args.cache_dir)
+    elif args.elf_weights:
+        download_elf_weights(cache_dir=args.cache_dir)
+    elif args.dataset:
+        download_dataset(args.dataset, cache_dir=args.cache_dir)
+
+
+if __name__ == "__main__":
+    main()
